Multi-target Phase 7 Live 적용

목적

replay에서 가장 안전한 후보였던 person_aware_merge 계열 설정을 실제 live_motion_viewer.py 측정에도 적용한다.

수정 파일

  • config/live_motion_tuning_isk.json
  • real-time/live_motion_viewer.py
  • tools/runtime_core/runtime_settings.py

변경 내용

  • live tuning에 object count estimator 파라미터를 추가했다.
  • protect_multi_object_candidates=true로 설정해 2명 근거가 있을 때 DBSCAN이 사람 후보를 1개로 접지 않도록 했다.
  • limit_output_to_object_count=false로 두어 replay 검증상 가장 안정적이었던 person_aware_merge 동작을 live 기본 후보로 반영했다.
  • live_motion_viewer.py가 새 detection 파라미터를 실제 처리 함수에 전달하도록 연결했다.

검증 명령 또는 확인 방법

python -B -c "import json; json.load(open('config/live_motion_tuning_isk.json', encoding='utf-8')); print('json ok')"
python -B -m tools.diagnostics.multitarget_stage_eval --session 20260508_193458 --mode person_aware_merge --expected-max 2 --min-separation-m 0.65 --min-doppler-bins 7 --min-score-ratio 0.05 --jump-threshold-m 0.85

결과

JSON 검증 통과. 20260508_193458 기준 person_aware_merge는 DBSCAN collapse 0.0%, 최종 2명 이상 표시율 77.6%, 3명 이상 과검출률 0.0%, track jump 0.0%로 확인됐다.

남은 위험 또는 다음 후보

live 환경에서는 실제 사람 수와 동선에 따라 false split이 달라질 수 있다. 다음 측정 후 새 live session을 Stage Debug로 cache 생성해 같은 KPI를 확인해야 한다.
