Streamlit RAI Collapse 진단 카드 오류 수정

목적

Stage Debug의 RAI Collapse vs Doppler-Slice Angle 섹션에서 정의되지 않은 _mini_metric_card 호출로 Streamlit 페이지가 중단되는 문제를 수정한다.

수정 파일

  • tools/lab/app.py

변경 내용

  • 존재하지 않는 _mini_metric_card 호출을 기존 공용 카드 함수 _stage_card 호출로 교체했다.

검증 명령 또는 확인 방법

python -B -c "from pathlib import Path; compile(Path('tools/lab/app.py').read_text(encoding='utf-8'), 'tools/lab/app.py', 'exec'); print('syntax ok')"
rg -n "_mini_metric_card" tools/lab/app.py

결과

syntax 검증을 통과했고, _mini_metric_card 잔여 호출이 없는 것을 확인했다.

남은 위험 또는 다음 후보

Streamlit 화면에서 브라우저 새로고침 후 해당 섹션이 정상 표시되는지 확인하면 된다.
