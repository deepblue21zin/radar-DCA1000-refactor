Multi-target Phase 4-5 Person-aware Merge 및 Tracker 완화 검증

목적

기준 세션 20260508_193458에서 DBSCAN이 실제 두 사람 후보를 1명으로 합치는 문제를 줄이고, tracker birth/association 완화가 효과적인지 단계적으로 검증했다.

수정 파일

  • tools/runtime_core/detection.py
  • tools/lab/stage_cache.py

변경 내용

  • detection에 protect_multi_object_candidates 옵션을 추가했다. object count estimate가 2 이상이면 DBSCAN이 후보를 1개로 접지 않고 RDA 후보를 유지한다.
  • detection에 limit_output_to_object_count 옵션을 추가했다. 필요 시 tracker 입력을 object count estimate로 제한할 수 있다.
  • Stage Cache에 person_aware_merge 모드를 추가했다. 이 모드는 multi-object 후보 보호만 켜고 tracker는 기존 설정을 사용한다.
  • Stage Cache에 multi_tracker_relaxed 모드를 추가했다. 이 모드는 person-aware 후보 보호, object count cap, 낮은 confirm hit 기준을 함께 검증한다.

검증 명령 또는 확인 방법

python -c "from pathlib import Path; compile(Path('tools/runtime_core/detection.py').read_text(encoding='utf-8'), 'tools/runtime_core/detection.py', 'exec'); compile(Path('tools/lab/stage_cache.py').read_text(encoding='utf-8'), 'tools/lab/stage_cache.py', 'exec'); print('syntax ok')"
python -B -m tools.lab.stage_cache --session 20260508_193458 --mode person_aware_merge --force
python -B -m tools.diagnostics.multitarget_stage_eval --session 20260508_193458 --mode person_aware_merge --expected-max 2 --min-separation-m 0.65 --min-doppler-bins 7 --min-score-ratio 0.05 --jump-threshold-m 0.85
python -B -m tools.lab.stage_cache --session 20260508_193458 --mode multi_tracker_relaxed --force
python -B -m tools.diagnostics.multitarget_stage_eval --session 20260508_193458 --mode multi_tracker_relaxed --expected-max 2 --min-separation-m 0.65 --min-doppler-bins 7 --min-score-ratio 0.05 --jump-threshold-m 0.85

중간 실험으로 confirm 2/3회 기준을 cap 없이 적용했을 때 2명 표시율은 높아졌지만 3개 이상 과분리가 크게 늘었다. 따라서 이번 기준 세션에서는 tracker를 크게 완화하는 것보다 person_aware_merge가 가장 균형이 좋다.

남은 위험 또는 다음 후보

  • person_aware_merge는 Stage Cache 검증 모드이며 아직 live 기본 설정으로 적용하지 않았다.
  • 실제 3명 세션에서는 over_expected_max 기준을 3으로 두고 별도 검증해야 한다.
  • 다음 단계는 Streamlit에서 ablation mode별 KPI를 한 화면에서 비교하고, 선택한 모드를 live 설정으로 옮기는 것이다.
