Multi-target Phase 6 Streamlit 평가 지표 추가

목적

2인 교차 세션 20260508_193458에서 단계별 replay 모드의 성능을 Streamlit Stage Debug 화면에서 한 번에 비교할 수 있게 한다.

수정 파일

  • tools/lab/app.py

변경 내용

  • Stage Debug ablation mode 목록에 rda_candidates, person_aware_merge, multi_tracker_relaxed, no_duplicate_suppression을 추가했다.
  • 모드별 cache 존재 여부와 multi-target 핵심 KPI를 비교하는 Ablation KPI Comparison 표를 추가했다.
  • KPI는 multi-object evidence, DBSCAN collapse, tracker collapse, 최종 2명 이상 표시율, 3명 이상 과검출률, RAI suspicious frame 수를 표시한다.

검증 명령 또는 확인 방법

python -B -c "from pathlib import Path; files=['tools/lab/app.py','real-time/live_motion_viewer.py','tools/runtime_core/runtime_settings.py','tools/runtime_core/detection.py','tools/lab/stage_cache.py','tools/diagnostics/multitarget_stage_eval.py']; [compile(Path(f).read_text(encoding='utf-8'), f, 'exec') for f in files]; print('syntax ok')"

결과

pyc 파일을 만들지 않는 방식으로 syntax 검증을 통과했다. Streamlit 실행 화면은 사용자가 열어 둔 Radar Lab에서 새로고침 후 확인하면 된다.

남은 위험 또는 다음 후보

KPI 표는 이미 생성된 Stage Cache를 비교한다. 새 모드를 처음 보는 세션은 해당 모드로 cache를 한 번 생성해야 수치가 채워진다.
