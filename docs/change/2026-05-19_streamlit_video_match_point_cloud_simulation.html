Streamlit Video Match point cloud simulation

목적

발표용 mp4 파일을 새로 만드는 방식이 아니라, Streamlit 안에서 실제 영상과 radar stage cache 시뮬레이션을 직접 비교할 수 있도록 한다. 측정할 때마다 Stage Debug에서 같은 시야의 point cloud simulation을 확인하고, Video Match에서 영상과 해당 simulation을 나란히 볼 수 있게 만든다.

수정 파일

  • tools/lab/app.py
  • docs/change/2026-05-19_streamlit_video_match_point_cloud_simulation.html

변경 내용

  • Stage Debug에 Same-view Point Cloud Simulation 섹션을 추가했다.
  • 선택한 stage cache frame과 stage를 바탕으로 7m x 7m ROI, radar 위치, trajectory, 사람형 point cloud를 렌더링한다.
  • Video Match에서 lab_data/영상데이터 아래 영상 파일을 직접 선택할 수 있게 했다.
  • Video Match에서 Stage Debug가 사용하는 stage cache simulation source를 선택할 수 있게 했다.
  • Video Match의 오른쪽 패널은 고정 preset 원/대각선이 아니라 선택한 stage cache trace의 실제 radar trajectory와 사람형 point cloud를 표시한다.

남은 위험 또는 다음 후보

  • 현재 Video Match는 영상 재생 시간과 radar frame slider를 자동 동기화하지 않는다. 정확한 동기화가 필요하면 영상 시작 offset과 frame-rate mapping 값을 별도 preset으로 저장해야 한다.
  • 사람형 point cloud는 stage cache의 중심 좌표를 기반으로 한 시각화용 cloud이다. 실제 low-level RDA dense point 전체를 그대로 3D로 투영한 것은 아니다.
