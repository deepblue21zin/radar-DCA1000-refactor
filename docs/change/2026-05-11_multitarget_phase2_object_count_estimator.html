Multi-target Phase 2 Object Count Estimator 추가

목적

tracker가 현재 프레임의 예상 객체 수를 모르는 상태에서 birth/association을 수행하는 문제를 줄이기 위해, detection 단계의 최종 merge 후보에서 독립 객체 수를 추정해 trace에 기록하도록 했다.

수정 파일

  • tools/runtime_core/detection.py
  • tools/diagnostics/multitarget_stage_eval.py

변경 내용

  • _estimate_object_count_from_candidates를 추가해 후보 간 xy 거리와 Doppler bin 차이를 기준으로 독립 객체 수를 추정한다.
  • detection trace에 object_count_estimator 블록을 추가한다.
  • 기준 세션에서 3명 과대 추정을 줄이기 위해 기본 Doppler 분리 기준을 7 bins로 조정했다.
  • 진단 리포트에 object_count_estimate 분포를 추가했다.

검증 명령 또는 확인 방법

python -c "from pathlib import Path; compile(Path('tools/runtime_core/detection.py').read_text(encoding='utf-8'), 'tools/runtime_core/detection.py', 'exec'); compile(Path('tools/diagnostics/multitarget_stage_eval.py').read_text(encoding='utf-8'), 'tools/diagnostics/multitarget_stage_eval.py', 'exec'); print('syntax ok')"
python -B -m tools.lab.stage_cache --session 20260508_193458 --mode baseline --force
python -B -m tools.diagnostics.multitarget_stage_eval --session 20260508_193458 --mode baseline --expected-max 2 --min-separation-m 0.65 --min-doppler-bins 7 --min-score-ratio 0.05 --jump-threshold-m 0.85

결과

  • 보고서: logs/diagnostics/multitarget_stage_eval_20260511_041249_20260508_193458/report.html
  • object_count_estimate 분포: 1명 92프레임, 2명 155프레임, 3명 3프레임
  • display_two_or_more_rate: 0.236
  • dbscan_collapse_rate_on_multi_evidence: 0.7215
  • tracker_collapse_rate_after_dbscan_multi: 0.631

남은 위험 또는 다음 후보

  • 이번 단계는 객체 수 관측값을 trace에 남기는 변경이며, 아직 DBSCAN/tracker 동작을 직접 바꾸지는 않는다.
  • 기준 세션에서 DBSCAN이 object count estimate 2인 프레임을 1개로 접는 비율이 높으므로, 다음 단계에서는 RDA 후보 유지와 DBSCAN/merge 정책을 object count와 연동해야 한다.
