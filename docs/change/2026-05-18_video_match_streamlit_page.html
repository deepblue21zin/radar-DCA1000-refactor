Streamlit 영상 매칭 비교 페이지

목적

실제 촬영 영상과 레이더 좌표계 시뮬레이션을 같은 화면에서 비교할 수 있도록 Streamlit Radar Lab에 영상 매칭 페이지를 추가했다. 왼쪽에는 lab_data/영상데이터의 mp4 영상을 표시하고, 오른쪽에는 7m x 7m 실험 공간을 레이더 기준 좌표계로 그린 same-view simulation을 표시한다.

수정 파일

  • tools/lab/app.py
  • docs/change/2026-05-18_video_match_streamlit_page.html

변경 내용

  • Streamlit sidebar에 Video Match 페이지를 추가했다.
  • 요청한 네 영상/로그 매칭을 고정 preset으로 등록했다.
  • preset 선택 UI와 매칭 목록 표를 추가하고, 선택한 항목의 왼쪽에는 영상, 오른쪽에는 7m x 7m 동일 시야 시뮬레이션을 보여준다.
  • 시뮬레이션에는 하단 중앙 레이더 위치, 7m x 7m ROI, 좌우 상단 시야 가이드, 예상 이동 경로, 진행률 marker를 표시한다.
  • 같은 session ID의 stage cache가 존재하면 오른쪽 시뮬레이션에 display/tracker trajectory를 자동 overlay하도록 했다.

결과

  • tools/lab/app.py 문법 검사를 통과했다.
  • git diff --check에서 공백 오류는 없었다. Windows 줄바꿈 경고만 확인됐다.
  • 요청한 네 mp4 파일은 모두 로컬에 존재한다.
  • 네 preset 모두 180개 sample의 기준 시뮬레이션 경로를 생성하는 것을 확인했다.

남은 위험 또는 다음 후보

  • 현재 로컬 lab_data/stage_cache에는 요청한 네 session ID의 stage cache가 없어 처음 화면에서는 시뮬레이션 기준 경로만 보인다.
  • 해당 session ID의 raw replay stage cache가 생성되면 같은 페이지에서 레이더 trajectory overlay가 자동으로 표시된다.
  • 카메라 영상의 실제 시간축과 레이더 frame index를 완전히 동기화하려면 시작 frame offset과 duration 보정값을 preset에 추가해야 한다.
